# 任务07：最小真实数据前端

目标：让用户通过本机网页读取已有巡检 SQLite 的资产、扫描、证据和调度状态。不增加网络探测，不增加业务写 API。

## 约束与设计

- React / TypeScript / Vite，浅底绿色，无图片素材、无循环动效。
- 以当前 OpenAPI 生成类型；请求集中在客户端层，不另造后端业务格式。
- 资产 UUID 是台账编号，不是身份认证；IP 是某次观测地址，不是当前在线承诺。
- 首两个资产如实显示人工登记；CPU、内存、进程未采集，不显示零值。
- 列表明确分页和已载入数量；扫描默认不把正序第一页当最新扫描。
- 页面刷新仅 GET；手动扫描仍由 CLI 完成。无模拟业务数据、无假操作按钮。
- 生产文件独立置于 frontend/dist，由 FastAPI 在 /console/ 提供；仅开放 127.0.0.1。不动说明站、进度库和线上站点。

另应用户明确要求，通过线上既有单项接口追加5项实际完成进度，保留原12项；不将此操作集成到巡检项目。

## 文件职责

- backend/app/console.py：静态交付与缺构建提示；backend/tests/test_console.py：边界回归。
- frontend/src/api-schema.d.ts：从现有 OpenAPI 生成；api.ts：请求、分页。
- frontend/src/model.ts：显示语义（未知、北京时间、记录排序）。
- frontend/src/App.tsx、components.tsx、styles.css：页面与只读状态。
- frontend/src/*.test.*：客户端/组件测试（隔离样例，不进入实际数据库）。
- frontend/README.md、docs/任务07-只读前端验收.md：使用方式与验证证据。
