日期：2026-11-15。依据：用户同意上轮“Windows 后台服务、不依赖个人登录”的方向，并授权完成后继续下一步；每项交付后汇报。无 Git 仓库，不创建虚构提交。

## 设计与边界

- 不改资产身份规则、不改每日一次名额、不新增扫描目标、不迁移数据库、不碰共享勾选。
- 采用独立调度工作进程，不在 FastAPI worker 中启动定时器。Windows SCM 系统服务托管工作进程；不用需要交互登录的任务承担正式托管。
- 不引入新的第三方服务包装器或在线下载。原生 Windows 服务桥接只做启动、停止和退出码上报；Python 标准库 ctypes 调用系统 API。安装需管理员，运行使用独立虚拟服务账户，而非管理员或 LocalSystem。
- 工程目录、解释器、配置和读写目录由安装脚本当前环境生成；新电脑仍需重新建环境、校验网卡和安装，不能复制旧服务注册或虚拟环境。Windows 专用探测不冒充跨平台。
- 工作进程定期调用现有 run-due CLI；每日名额仍在 SQLite。工作进程单实例锁独立于扫描写锁，手动入口不变。子进程有预算；停止和服务退出必须清理子进程，不能产生后台孤儿扫描。
- 心跳为数据库旁独立 JSON 文件，不是网络检测结果。包含配置/数据库身份指纹、实例、时间、执行状态；原子替换。状态丢失、损坏、过期、时钟异常均不得当成正常。
- 下一步添加只读状态和调度记录 API；不开放写 API，不做无鉴权“立即扫描”。路径及凭据不在状态接口泄露。API 读取不发扫描、不创建数据库、不修复遗留记录。
- 旧登录任务仅在新服务已成功启动、心跳通过后停用，保留可回退；切换失败恢复旧状态。不删除旧任务。
