# 任务04验收：自动资产档案、每日一次及手动扫描

日期：2026-11-15，Asia/Shanghai。后端版本0.4.0，数据库0003_automatic_discovery。
用户要求本轮直接实现，完成后汇报；本轮不继续Agent/业务前端。

## 1. 本轮交付与边界

- 扫描结束自动新建/关联资产，通用程序执行，不需要AI逐台分析、填名称或调用register。
- 同scope有效MAC历史唯一、同次不重复时沿用UUID；IP不参与身份判定。
- 无MAC/冲突也自动建档，但标needs_review，不凭IP/名称合并。
- 自动档案discovered，旧人工档案managed；来源保留，采集授权仍not_enrolled。
- 手动与每日入口共用执行器、报告与写入锁；每日名额持久化。
- Windows每日09:00及用户登录补当天任务已安装；Interactive/Limited，不保存密码。
- 每日失败/部分完成计入当天尝试，busy不占名额；无后台无限重扫。
- 只读HTTP契约更新到0.4.0；没有新增无鉴权远程扫描写API、没有扫描网页按钮。

所有条件与日常命令见《自动资产与每日扫描-使用说明》。
MAC线索关联不等于设备认证；不能排除MAC克隆、缓存和物理网络复用。
