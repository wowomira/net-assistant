## 2. 项目已具备的运行功能

| 模块 | 已实现 | 限制 |
|---|---|---|
| 范围配置与扫描 | IPv4单地址/CIDR/起止范围、排除、源地址、端口、预算、并发；手动CLI | 需显式授权；当前115常用TCP，不是全端口、UDP、IPv6或漏洞扫描 |
| 探测与证据 | Windows ICMP、同链路ARP、TCP；按命中条件取HTTP/TLS/有限横幅证据 | 超时不等于关闭；配置支持与本次实际取得证据分开 |
| 数据库 | SQLite保存范围、任务、发现、探测、资产、关联、审计和每日执行记录 | 不主动采集；迁移前备份不等于每日自动备份轮换 |
| 资产台账 | 稳定UUID、扫描后自动建档/关联、保留决策、人工CLI纠错 | MAC只是同scope保守线索，不证明设备身份、所有权或采集授权 |
| 每日与手动 | 独立worker、Windows服务、每日唯一名额、共用扫描锁；手动不占每日名额 | 每天最多一次自动尝试，不保证成功；失败不会无限补扫 |
| 系统托管 | 独立虚拟服务账户、自动启动配置、有限进程恢复与子进程清理 | 不需要个人登录的服务配置已安装；真实重启/注销仍未测 |
| 只读API | 发现、资产、证据、关联审计、调度心跳和每日历史 | API本身仍需单独启动；无安全写API/网页扫描按钮 |
| 结果语义 | 区分心跳、扫描结果、未到期、失败、未知和过期 | 心跳不是扫描成功或完整就绪证明 |
