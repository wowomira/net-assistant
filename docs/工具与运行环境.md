# 工具与运行环境

> **2026-11-16 更新：下文保留旧“系统安装开发者路径”的说明，不再是唯一入口。**
> 当前 GitHub 交付提供固定版本私人 Release 资源包和 `bootstrap.ps1`：
> Python/Node/npm/Gatus/SSH/Chromium headless shell/Swagger 均使用项目内副本。
> Nmap 由用户自行取得后通过 `import-nmap` 复制进项目，Npcap 由用户安装授权。
> 新流程、版本、目录及实际验收边界以 `Windows协作与离线运行.md`、
> `runtime.lock.json` 和对应交付验收报告为准。
> 不把旧 `.venv` 绑定或全局 PATH 作为便携入口的运行依赖。

交付目标是 **0.10.0 可重建源码协作环境**，不是复制整台开发电脑作为便携产品。
入口为仓库根 `scripts/workspace.py`，`doctor` 显示工具位置，不输出密码/环境变量值。

| 组件 | 用途 | 新协作者位置与获得方式 |
|---|---|---|
| Python 3.13 x64 | 后端与测试 | 自行安装并加入 PATH；`setup` 在 `.runtime/venv` 重建依赖，不提交原作者 `.venv` |
| Node.js 24.x / npm | 前端开发、测试、构建 | 自行安装并加入 PATH；锁定 package-lock，`npm ci` 安装到独立构建目录 |
| Nmap | 真正执行扫描 | 自行安装并加入 PATH；新配置默认 `nmap_path: nmap`，非标准位置写进自己的 `.runtime/configs/scope.local.json` |
| Gatus v5.38.0 | 持续服务监控、真实工具回归 | 原 `backend/scripts/manage-gatus.ps1 -Action Build` 显式构建到 `backend/tools/gatus/bin/gatus.exe` |
| Windows PowerShell | 本机网卡/地址/邻居快照 | Windows 自带，按 `SystemRoot` 定位 `System32/WindowsPowerShell/v1.0/powershell.exe` |
| Microsoft Edge | 可选网页截图 | 自行安装；Playwright 使用 `msedge` channel，不读取个人浏览器资料 |
| OpenSSH 客户端 | 受控 SSH | Windows OpenSSH Client 可选功能或独立安装；代码从 PATH 找 `ssh`，不提交私钥 |

只启动 API、登录、读取空台账不需要 Nmap/Gatus/Edge。
Python 协议包装好不等于外部工具、驱动、权限、目标与真实设备兼容都已通过。
本机原工具不搬动、不升级、不替换，仍保留原位置。

## 安全默认配置

在 `.runtime/configs` 生成，重复安装不覆盖自己的改动：

- 只给 `127.0.0.1` 回环示例，OS 指纹、mDNS、截图关闭；
- 每日扫描停用；交换机停用且 `profiles=[]`；
- Gatus 监控 `endpoints=[]`；SSH `targets=[]`，无默认设备或私钥。

打开页面或执行 `check` 不会探测网络。真正启用时按后端说明显式配置并运行，
不要把作者实验网或示例目标当作自己的授权范围。

## Gatus

在 `net-assistant/backend` 下执行：

```powershell
.\scripts\manage-gatus.ps1 -Action Build
```

需要先自行安装 Go。原脚本固定 `github.com/TwiN/gatus/v5@v5.38.0`，
使用 `GOTOOLCHAIN=go1.26.11`，依赖网络并将缓存放在项目工具目录。
已有程序拒绝覆盖，保留 Gatus-LICENSE。
本轮在新 Python 环境复用本机现有 Gatus 做真实回环测试，不冒充第二台机器的 Go 构建验收。

## 未把系统目录直接塞进 Git 的原因和边界

旧 `.venv` 带本机解释器绑定，单复制 python.exe、PowerShell 或 Edge exe 不能视作新机可运行安装。
系统组件和 Nmap/Npcap 的再分发条件本轮未完成独立核验，因此不把“本机能读到文件”当作可以随项目重打包的证据。
不上传个人浏览器数据、系统目录、开发缓存或私有工作库。

如果需要**离线、双击运行、所有工具随包**的产品，仍需单独完成安装包/哈希/许可、离线依赖、
驱动与权限、第二台干净 Windows 的完整验收；当前源码协作交付不冒充该发行包。
